- **쫄지 마세요, 코딩하지 않을 겁니다.** **Claude Code에게 명령할 거에요**, 규칙은 `CLAUDE.md`에 들어 있습니다.
- 이 사이트는 **인터넷에 공개**됩니다. 전화번호·학번 같은 개인 정보는 넣지 마세요.

## 처음 한 번 — 준비와 연결

### 1. 준비물
| 준비물 | 확인 방법 |
|---|---|
| Claude 유료 계정(Pro 이상)과 Claude 데스크톱 앱 | 앱에 로그인하고 왼쪽 위 **Code** 탭이 보이면 OK |
| GitHub 계정 | github.com 에서 가입. 아이디는 사이트 주소가 되니 영문 소문자로 짧게 |
| git | 터미널에 `git --version` 입력. 맥에서 설치 창이 뜨면 설치를 누르고 기다립니다 |
| GitHub CLI | cli.github.com 에서 내 컴퓨터용 설치 파일을 받아 설치. 터미널에 `gh --version` 이 나오면 OK |

### 2. GitHub 로그인 (터미널에서 직접, 한 번만)
```
gh auth login --web --git-protocol https
```
화면에 나온 8자리 코드를 복사 → 브라우저가 열리면 붙여 넣고 승인합니다.
`gh auth status` 에 "Logged in" 이 보이면 끝입니다.

### 3. 폴더 열기
1. 받은 `si-archive` 폴더를 원하는 곳(예: 문서 폴더)에 둡니다.
2. Claude 데스크톱 앱 → **Code** 탭 → 폴더 선택에서 `si-archive` 폴더를 고릅니다.

### 4. 서버에 연결
Claude에게 이렇게 말합니다.
```
GitHub에 연결해 줘. 내 이름은 ○○○이야.
```
Claude가 저장소를 만들고 공개 주소를 켜 줍니다. 1~2분 뒤 알려 준 주소를 열어 92칸 격자가 보이면 성공입니다.
**이 주소를 TA에게 제출하세요.**

## 매번 하는 일

### 따라 하기 올리기
카탈로그(갤러리)에서 그 번호의 **한 줄** 또는 **5칸 명세**를 복사해서 붙입니다.
```
23번 따라 하기 추가해 줘. 넣을 문장: (복사한 문장)
```

### 내 응용 올리기
원본에서 무엇을 바꿨는지 함께 말합니다.
```
23번 내 응용 만들어 줘. 넣을 문장: (내가 쓴 문장)
이름: 재생목록 시트 / 바꾼 점: 바텀 시트를 음악 재생목록으로, 높이 3단계에 뒤 화면 어두워짐 추가
```

### 확인 → 올리기
1. Claude가 알려 준 파일을 더블클릭해 브라우저에서 직접 조작해 봅니다.
2. 마음에 들면 `올려 줘` → 1~2분 뒤 공개 주소에 반영됩니다.

## 이렇게 말하면 됩니다

| 하고 싶은 것 | 말하기 | 단축어 |
|---|---|---|
| 실습 추가 | "23번 따라 하기 추가해 줘" / "23번 내 응용 만들어 줘" | `/add 23 follow` · `/add 23 mine` |
| 값 하나 고치기 | "23번 내 응용에서 붙는 시간만 0.35초에서 0.5초로" | — |
| 공개 주소에 올리기 | "올려 줘" | `/publish` |
| 되돌리기 | "방금 올린 거 취소해 줘" / "어제 버전으로 돌려 줘" | `/undo` |
| 목록과 파일 맞는지 점검 | "점검해 줘" | `/check` |

## 지켜 주세요
- **한 번에 하나만.** 세 개를 한꺼번에 시키면 어디서 틀렸는지 찾기 어렵습니다.
- **고칠 때는 값 하나만.** "더 멋지게"보다 "튕기는 높이만 300에서 200으로"가 정확합니다.
- **기술 이름 대신 보이는 것과 숫자로 말합니다.** 카탈로그 부록의 "기술 이름 대신 쓰는 말"을 참고하세요.
- 영상·이미지는 **파일 하나에 20MB 이하**. ProtoPie 녹화는 압축해서 넣습니다.
- 첫 화면(`index.html`)과 `data/works.js` 는 Claude가 관리합니다. 직접 고치지 않아도 됩니다.

## 막혔을 때

| 증상 | 해 볼 것 |
|---|---|
| 공개 주소가 404 | 올린 지 2분이 안 됐으면 기다립니다. 그래도 안 되면 "공개 주소가 안 열려, 확인해 줘" |
| 내 사이트에 안 바뀐 옛 화면이 보임 | 브라우저 새로고침(⌘⇧R / Ctrl+Shift+R) |
| 다른 실습이 망가졌어요 | "방금 올린 거 취소해 줘" → 되돌린 뒤 다시 하나씩 |
| `gh: command not found` | GitHub CLI 설치 후 터미널을 껐다 켭니다 |
| 로그인하라고 나와요 | 위 "2. GitHub 로그인"을 터미널에서 다시 실행 |
